## 项目简介

- 目标: 使用多个 AI 编码代理收集和分析文档，并以易读的网页形式呈现
- 重点: 用不同模型处理同一主题，比较产出质量和生产效率
- 方式: 持续迭代改进（爬取准确度、UI/UX、自动化流水线）
