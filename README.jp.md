# ドキュメントクローリング Web プロジェクト

[English](./README.md) | [한국어](./README.kr.md) | [日本語](./README.jp.md) | [中文](./README.zh.md) | [Français](./README.fr.md)

> `codex`、`gemini-cli`、`claude-code`、`copilot-cli` を使って
> ドキュメントをクローリングし、Web ページとして整理する実験プロジェクトです。

## モデル評価ランキング（現在）

| 順位 | モデル |
|---|---|
| 🥇 1位 | **codex** |
| 🥈 2位 | **gemini-cli** |
| 🥉 3位 | **antigravity** |
| 4位 | **claude code** |
| 5位 | **copilot** |

## プロジェクト概要

- 目的: 複数の AI コーディングエージェントで文書を収集・分析し、見やすい Web ページとして提供する
- ポイント: 同じテーマを各モデルで試し、成果物の完成度と生産性を比較する
- 進め方: 反復的な改善（クローリング精度、UI/UX、自動化パイプライン）
